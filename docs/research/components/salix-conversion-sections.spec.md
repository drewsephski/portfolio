# SalixConversionSections Specification

## Overview
- Target: `app/salix/salix-conversion-sections.tsx`
- Interaction model: click-driven analytics tabs, pricing toggle, and FAQ accordion.

## Sections
- Growth Gear desktop padding `110px 30px 120px`; centered heading; three pill tabs; screenshot inside a pale framed viewport. Mobile padding 60px 20px.
- Reviews: heading plus asymmetric bento grid. Highlight card is pink-red; revenue card is blue. Desktop section about 879px; mobile stacks.
- Pricing: two bordered cards, monthly/yearly segmented control, source prices $39 and $79 monthly, visible SAVE 20% badge.
- FAQ: left title and right single-open accordion. Source first answer must be verbatim.
- CTA and footer match the source copy and use cta-dashboard.png and logo.svg.

## Typography and responsive
Desktop h2 is Geist 44px/52.8px, -2.5px; mobile 28px/33.6px, -1px. Body is Inter 14–16px. Collapse multi-column layouts at 768px.
